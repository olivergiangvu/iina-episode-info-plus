# Episode Info+ v1.3.4-beta.3 — Verified TMDb alternate-title discovery

HLS `index.m3u8` may expose `City of Splendour · S01E02 · Episode 2`
without external IDs; the canonical series is called `This City Never Sleeps`
(2026, IMDb tt39443161, TMDb 295002) in other catalogs.

The Episode Info+ parser strips only structured S/E middle dots (beta.2).
This update checks up to eight returned TMDb show details for exact
provider-verified alternative titles, instead of the top three.

No fuzzy matching, guessed TMDb ID, unverified alias or blind fallback.
If TMDb does not return the candidate or the alias is missing in the
provider catalog, the match remains unresolved until manual selection.
The plugin still verifies episode S/E and runtime.

CI-only Mac canary artifact. Not released; stable v1.3.3 unchanged.
