# Episode Info Plus v1.3.5 — Stable

**Promoted 12 November 2026 following successful CI release gates and user-reported Mac verification.**

This release replaces non-compliant v1.3.4 as the current Stable. The historical v1.3.4 GitHub release is retained as a **pre-release** for traceability, not recommended for installation.

## Restored and verified
- Verified EP+ TMDB metadata automatically downloads the correct portrait poster for IINA native macOS Now Playing.
- mpv `video-add ... auto+attached-picture` attaches the artwork to the current media without taking control of playback or creating a separate media session.
- Title, position, duration and media controls remain IINA-native.
- On episode change or clearing selection, stale artwork downloads are invalidated.

## All v1.3.4 improvements preserved
- Opaque AIOStreams HLS stream recognition, including correct clean player labels such as `Hell Barrister · S01E01 · Episode 1`.
- Conservative exact TMDB / TVmaze matching and 2016-vs-2026 episode-year safeguards.
- Light/Dark Glass overlay, Cast/Up Next, subtitles and intro/credits skip.
- No changes to Trakt+ or HomeDocker components.

## Mandatory release gates added
- CI runs the original metadata, UI and identity suites plus permanent protected-feature checks and Now Playing tests.
- CI checks the **actual installable .iinaplgz** for missing bundled modules and assets.
- Live IINA/macOS playback remains a required acceptance stage for native behavior.
- A stable release must never silently drop a previously accepted feature.

## Installation
Install the `Episode-Info-Plus-1.3.5.iinaplgz` attachment of this GitHub release through IINA. Same plugin identifier; replaces older installations.

**Rollback:** use an explicitly marked older release only when necessary. Version v1.3.4 is historical/non-compliant because it omitted previously verified Now Playing artwork.
