# Episode Info Plus v1.3.4 — Stable

Promoted from `v1.3.4-beta.2` on 7 November 2026 after CI regression checks and live macOS/IINA tests with AIOStreams HLS playback.

## Improvements

- **Opaque HLS playback:** recognizes an exact IINA player title in the form `Hell Barrister · S01E01 · Episode 1` when a CDN only provides a random `.m3u8` filename. A player title is an **unverified candidate**, not proof of identity.
- **Strict verification:** verifies the actual show and episode with TMDB; independent TVmaze fallback requires exact show name, season/episode and compatible runtime. Conflicts and ambiguous results remain unmatched rather than invented.
- **Preserve good filenames:** genuine release filenames (e.g. `Mystic.Nine.S01E08.2026.2160p.WEB-DL.mkv`) outrank generic player labels. Random-looking HLS tokens do not overwrite a clean series title.
- **Episode air year:** retained safeguards distinguishing a 2026 episode from a similarly titled series first premiered in 2016, and rejecting cases that cannot be confirmed.
- Retains existing subtitle integration, overlay, cast/Up Next, Light/Dark Glass appearance, request handling and security restrictions.

## Acceptance evidence

- **GitHub CI** on the release PR is required before promotion; syntax, metadata identification, actual parsing logic and upstream/interface regressions.
- User's Mac screenshot: `Hell Barrister S01E01` shows English Episode 1, air date (2026-10-05), cast credits and Up Next `S01E02`, despite opaque HLS filename. Existing Trakt+ handling is independent.
- These are functional UI/recognition tests, not a guarantee that every regional series has a metadata record.

## Upgrade and rollback

- Stable version `1.3.4`; `ghVersion=27` (up from beta.2 26 and previous stable 1.3.3). Same IINA identifier `io.github.olivergiangvu.iinaepisodeinfoplus`.
- Install `Episode-Info-Plus-1.3.4.iinaplgz` from GitHub Releases or IINA's GitHub installer after the new release is published.
- For rollback install the existing **v1.3.3** stable asset from [GitHub Releases](https://github.com/olivergiangvu/iina-episode-info-plus/releases). Keep a copy of plugin settings if manually reinstalling; do not share API keys.

## Scope

No changes to Trakt+, AIOStreams, HomeDocker, Metadata Bridge, stream playback IDs or Trakt scrobbling writes. This plugin only displays episode/movie metadata; provider verification and no-match protections remain enabled.

Independent fork of Zain Imam's IINA Episode Info (MIT).
