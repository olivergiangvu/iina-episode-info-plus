# Episode Info Plus v1.3.3 — Stable

Promoted from **v1.3.3-beta.9** after visual confirmation in IINA/macOS on The Diplomat S02E04 with Glass overlay and native translucent Light sidebar. Promotion only changes release metadata, tests, notes and packaging workflow. No playback matching, UI CSS, TMDB/TVmaze, subtitle, skip-intro or network logic changes from the tested beta.

## Refined macOS Light/Dark presentation

- **Light Glass:** unoutlined, crisp neutral-dark typography on a uniform translucent neutral-grey film, with readable episode title, plot, metadata, Cast and Up Next. Removes the failed white-letter outline from beta.8 and the uneven central haze from beta.5/6.
- **Dark Glass:** preserves the approved smoked-glass appearance and bright text.
- **Sidebar:** IINA-style native transparency, stronger Light Mode hierarchy and microtext, readable TMDB verification and manual search link, warm amber rating.
- **Shade, card width, poster position, Frosted/Colorful/Clear, Cast and Up Next settings:** preserved across upgrades.

## Matching and service compatibility (unchanged)

TMDB-first and TVmaze fallback matching, Comet/AIOStreams/MediaFusion and HLS episode identity handling, manual lookup, subtitles (OpenSubtitles/SUBDL/Wyzie), and Skip Intro/Credits are unchanged from beta.9. Trakt+ remains a separate plugin.

## Upgrade, rollback and verification

- Official IINA plugin identifier remains `io.github.olivergiangvu.iinaepisodeinfoplus`.
- `ghVersion=24` advances beyond beta.9's 23 and previous Stable v1.3.2's 14 so beta testers can receive this Stable update.
- Install with the versioned `Episode-Info-Plus-1.3.3.iinaplgz` from Releases or via the configured GitHub plugin repository.
- IINA visual feedback: The Diplomat S02E04 Light Mode card consistent with sidebar and native OSD approach. CI must pass final manifest and package validation.
- Previous Stable v1.3.2 remains on Releases for rollback.
