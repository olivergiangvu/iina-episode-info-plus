# v1.3.4 — Retired / Non-compliant release

> **Retired on 12 November 2026. This is NOT a supported Stable version.** Do not install this build as the latest Stable.

The v1.3.4 release retained AIOStreams HLS matching improvements but dropped an already Mac-verified feature: EP+ portrait artwork injection into IINA native macOS Now Playing (`epplus-now-playing.js` and verified episode-selection hook). The release archive also omitted the module. This violates the user's no-regression Stable policy.

**Replacement:** [v1.3.5 Stable](https://github.com/olivergiangvu/iina-episode-info-plus/releases/tag/v1.3.5) restores the artwork and adds permanent protected feature, packaging and native integration acceptance gates.

This earlier tag and artifact are preserved for **historical audit/rollback only**, not as a recommended Stable. The original v1.3.4 release notes are preserved in [docs/releases/v1.3.4.md](https://github.com/olivergiangvu/iina-episode-info-plus/blob/main/docs/releases/v1.3.4.md).

**Policy:** A release must be a tested superset of all previously accepted functionality, unless a feature removal is explicitly approved.
