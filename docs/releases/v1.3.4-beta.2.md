# Episode Info+ v1.3.4-beta.2 — HLS structured episode-label canary

Fixes recognition of a generic `index.m3u8` stream when IINA's mpv
media-title is formatted as `City of Splendour · S01E01 · Episode 1`.
The explicit `SxxExx` marker is retained while adjacent decorative middle
dots are stripped from the series and episode title.

This is a parser-only fix. TMDB/TVmaze must independently verify the real
show and S/E; the provider may use the English name `This City Never Sleeps`,
original Chinese name `璀璨之城`, TMDB 295002 / IMDb tt39443161.
No blind alias, invented ID or unattended scrobbling is allowed.

CI artifact from PR #12 is a Mac-only test build, not a release. Stable
v1.3.3 unchanged. No data migration, server stack change, or token changes.
